# VQA Lab — GitHub Pages

Laboratório interativo de Visual Question Answering (VQA).

## Publicar
1. Crie um repositório no GitHub (neste caso, `cv-pos`).
2. Envie os arquivos `index.html` e `.nojekyll` para a raiz do repositório, na branch `main`.
3. Acesse **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione **main**, pasta **/(root)**, e salve.

O site ficará em `https://iegawa.github.io/cv-pos/`.

## Observações
- As cenas e respostas são simulações didáticas, não inferência real de um VLM.
- A visualização BPE `o200k_base` depende de uma biblioteca externa carregada pela internet.
- Não inclua chaves de API neste repositório público.
